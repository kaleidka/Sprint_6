# Проект Sprint_6: Автотесты для сервиса «Яндекс.Самокат»

Этот проект представляет собой набор автотестов для учебного сервиса «Яндекс.Самокат». Тесты написаны с использованием Selenium и Allure для генерации отчётов.

## Описание проекта

### Цель проекта
Цель проекта — автоматизировать тестирование ключевых сценариев работы сервиса «Яндекс.Самокат». В рамках проекта были реализованы следующие тесты:

1. **Тестирование выпадающего списка в разделе «Вопросы о важном»**:
   - Проверка, что при нажатии на вопрос отображается соответствующий ответ.

2. **Тестирование процесса заказа самоката**:
   - Проверка позитивного сценария заказа с двумя наборами данных.
   - Проверка точек входа (кнопки «Заказать» вверху и внизу страницы).

3. **Тестирование переходов по логотипам**:
   - Проверка, что клик по логотипу «Самокат» возвращает на главную страницу.
   - Проверка, что клик по логотипу «Яндекс» открывает главную страницу Дзена.

### Технологии
- **Selenium**: Для автоматизации взаимодействия с веб-элементами.
- **Allure**: Для генерации отчётов о выполнении тестов.
- **Pytest**: Для организации и запуска тестов.
- **Page Object Model**: Для структурирования кода и улучшения поддерживаемости.

### Запуск тестов
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
 
2. Запустите тесты с генерацией Allure-отчёта:
   pytest --alluredir=allure-results  

3. Откройте отчёт Allure:
   allure serve allure-results
